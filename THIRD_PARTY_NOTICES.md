# Происхождение материалов

Численные реализации `BucketMethods.c` сгенерированы локальной Qwen2.5-Coder-14B-Instruct-4bit через ARPO Solver. Все шесть конечных файлов перенесены без изменений; их SHA256 приведены в `runs/experiment-20261007-161356-588ed87a/experiment.json` и итоговом отчёте.

Общий ACOM каркас создан eco-wizard и подготовлен организатором до генерации. Независимые проверки и отчёт подготовлены организатором Codex. Автор лабораторной — Фирсова Валерия Дмитриевна, группа 24ТИДИ.

`AssemblyFiles/Mac/build.py` адаптирован из автономного сборщика проекта [ARPO Solver](https://github.com/Dezmant8/ARPO_solver_macos). Он использует только стандартную библиотеку Python; лицензия исходного сборщика сохранена в `licenses/ARPO-MIT.txt`.

Eco SDK является внешней зависимостью, получаемой у преподавателя отдельно. Заголовки, библиотеки, ZIP поставки SDK и eco-wizard в репозитории отсутствуют. Лицензия этого репозитория не распространяется на отдельно полученный SDK или веса модели.
